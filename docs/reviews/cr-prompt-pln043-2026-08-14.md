## 审查重点（硬约束红线，逐条核对）
1. **原语化等价性（最高优先）**：4 原语与 act() 原内联段**逐行等价**——对照 git diff 逐段核对：草稿复用条件、记忆检索去重、三层前缀 prompt 拼接、tool calling/JSON fallback、超时兜底、_record_action_metric 参数，任何顺序/字段差异都是 P0。
2. **包装非重写**：action_workflows.py 的 decide 节点必须**复用原语**，不得重新实现决策逻辑（token 分级、合法目标校验、净化等逻辑不得复制粘贴）。
3. **开关语义**：BOTC_WORKFLOW_ACTIONS 默认 off；关闭时 act() 走原路径零差异；路由失败回退原路径（except 兜底）。
4. **观点演化闭环**：record 节点——有激活观点时 update_with_new_evidence（updated→update_confidence / superseded→supersede）；无激活观点时**创建软印象观点**（subject_name 从 reasoning 提取、不 gate 不注入发言、已有同 subject 观点不重复创建）；reasoning 无可提取玩家名时跳过（不产生噪音观点）。
5. **信息隔离**：recall 用 build_memory_snapshot（排除 evil_teammates/evil_bluffs）；观点回写证据只取 reasoning 文本；观点摘要只进 user 段（system 前缀稳定 D013/D014）。
6. **validate 节点**：decision 无 action 字段时回退 fallback（workflow_invalid_decision）；fallback 决策必须合法。
7. **测试质量**：test_action_workflows.py 是否真实覆盖（开关开/关对比、validate 假阴防护——DummyBackend 空 JSON 会被 normalize 兜底导致 validate 测试假阴，检查是否 monkeypatch _decide_via_llm）；测试是否隔离 BOTC_DATA_DIR（防 agents/、storyteller/ 污染仓库根）。
