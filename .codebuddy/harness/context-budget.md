# 上下文预算 (context-budget)

> 管理 agent 上下文窗口，防止溢出。**硬上限：32768 字节**。

## 预算分配（建议）

| 类别 | 预算（字节） | 说明 |
|------|----------:|------|
| 入口文件 AGENTS.md | ≤ 8192 | 操作手册 + 硬约束 + 规则加载指引 |
| 项目认知 MEMORY.md | ≤ 8192 | 启动链 + 模块速查 + 关键状态 + Auto Memory |
| 规则文件（按需加载） | ≤ 8192 | 命中模块叠加，总 ≤ 32768 |
| 进度/决策/文档 | 机动 | 按需读取，不常驻 |
| **合计硬上限** | **32768** | 超出优先精简 MEMORY 历史，其次按需加载规则 |

## 溢出处理

1. **第一优先**：精简 `MEMORY.md` 的 Auto Memory 历史（保留近 30 天 + 长期规律）。
2. **第二优先**：按需加载 `.codebuddy/rules/` 对应模块，而非全量加载。
3. **第三优先**：将细节移入子文档（如 `tech-traps.md`），入口只留索引。

## 监控

- 每次会话启动时估算已加载字节；接近 32768 时告警并触发溢出处理。
- 单文件规则 < 80 行、入口 < 200 行、MEMORY < 200 行（见 DECISIONS D002）。
