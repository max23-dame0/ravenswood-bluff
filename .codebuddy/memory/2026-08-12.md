## D017 验收 flaky 根因修复（2026-08-13，用户要求解决 6 项 slow 失败）

用户选择 A（保留 ruff 0.16.1 格式改动）+ 要求解决 6 项 slow 验收 flaky。已修复：

**根因**（非 mock 噪声，是生产行为缺陷）：vote 走本地判定路径，suspicion 常落 threshold±margin(0.06) 模糊带 → `DecisionEngine.persona_vote_bias` 兜底；该函数只看 `decision_style` 文案（`refresh_persona_profile` 用 `_pick_stable` 随机 pick，与 archetype 弱相关）→ aggressive/silent 全投 yes（`aggressive_vote_push_rate 1.0 <= 1.0`）、5 个 archetype 行为签名趋同（ai_evaluation `persona_diversity_score 0.2`）。

**修复**：`persona_vote_bias` good 分支先按 `archetype.assertiveness`（Archetype 实例，persona_profile["archetype"]）定倾向：high（aggressive/paranoid/strategist）→ yes；low（silent/cooperative/protector/outsider_vibe）→ no；neutral 回退文案。evil 分支不动。诊断方法：`tmp_work/diag_vote.py`（suspicion/threshold/decision 按 archetype 打印）。

**验证**：全量 **676（含 slow）/ 0 failed / 0 errors** + ruff 0 + format 0 + 10/10 gate + mock 8 人局 game_over。DECISIONS D017 登记；PROGRESS 验证状态表/任务 24/会话记录更新；MEMORY.md Auto Memory 更新。
