## 🔍 缓存命中率低根因分析（2026-08-04 用户提供当日 350,211 数据：Input hit 40,448 / miss 277,377 = 12.7%）
- **量化验证（recent_3 llm.jsonl）**：defense_speech 10 次调用 system 6 变体 / user1 10 变体 → 命中 6%；night_action 8 次 system 5 变体 / user1 8 变体 → 14%；动作类总 9.3%、全量 11.9%，与用户数据吻合。
- **根因 1（system 层）**：`stable_rules` 只有「公共规则+玩家名单」~382/1757 字符稳定，在 `【你的身份】Player X…角色…阵营…` 处断裂（每玩家不同）；动作类型/JSON schema/目标仍在 system 内（位置 1574+）→ 前缀在 system 中部即断。

- **改进方案**：P0 动作类型/JSON schema/目标从 system 移到最末 user 消息（同玩家 system 稳定）；P1 episodic/social/tiered 按阶段快照固定或移末条 + deception_budget 移末条；P2 草稿生成 prompt 三层化、说书人/evil 频道补 thinking=disabled。预期命中率 12.7%→60%+，输入未命中 -60%。
