- 根因 1（Windows-only 解释器路径）：19 个测试 + 19 个 scripts 硬编码 `repo_root / '.venv' / 'Scripts' / 'python.exe'`（含 benchmark 里的 `'.\\\\.venv\\\\Scripts\\\\python.exe'`）。修复：全部替换为 `sys.executable`（35 文件），并补 `import sys`；`scripts/README.md` 同步改约定并加禁止硬编码提示。
- 根因 2（父目录不存在）：`tests/test_runs/` 被 gitignore，CI 全新 checkout 无此目录；`test_api_server.py` 与 `test_storyteller_judgement_logging.py` 用 `mkdir(exist_ok=True)` 未加 `parents=True`。修复：改为 `mkdir(parents=True, exist_ok=True)`。
- 验证（本地删掉 tests/test_runs 模拟干净 CI）：`pytest tests -q` 447 passed；`ruff check src tests scripts` All checks passed；`ruff format --check` 182 files already formatted。
- 教训（记入陷阱清单）：子进程解释器一律用 `sys.executable`；测试产物目录一律 `parents=True`——被 gitignore 的目录在 CI 上必不存在。
